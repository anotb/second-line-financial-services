## Companion Excel — gap-and-evidence matrix tabs

Render the matrix via the `xlsx` skill. One tab per substantive section; the spine column structure is consistent across tabs so reviewers can work their domain.

- **Tab 1 — Document-request matrix.** Columns: request_id, request_item, domain, source_location, evidence_pin, reviewer_role, status, due_date, redaction_required, notes.
- **Tab 2 — Form ADV cross-check.** Columns: adv_item, current_value, source_check, consistency_check (website / marketing / contract / fee schedule), discrepancy_flag, owner_role, due_date.
- **Tab 3 — Rule 206(4)-7 program.** Columns: element, status, last_review_date, evidence_pin, owner_role, gap_flag.
- **Tab 4 — Rule 204A-1 code of ethics.** Columns: element (access-person list / quarterly reports / annual holdings / pre-clearance / violations), status, last_period_end, evidence_pin, owner_role, gap_flag.
- **Tab 5 — Rule 206(4)-2 custody.** Columns: account / SLOA / fund, custodian, custody-rule treatment, last surprise audit / private-fund-audit date, owner_role, gap_flag.
- **Tab 6 — Rule 206(4)-1 marketing.** Columns: ad_id, channel, claims, substantiation_pin, hypothetical / testimonial / third-party-rating flags, (d)(6) policy applied, owner_role, gap_flag.
- **Tab 7 — Rule 204-2 / 17a-3 / 17a-4 books-and-records inventory.** Columns: record_type, system_of_record, retention_through, e_records_compliance, owner_role, gap_flag.
- **Tab 8 — Form PF (if applicable).** Columns: filing_period, threshold_class, filing_date, current_event_filings, owner_role, gap_flag.
- **Tab 9 — Reg BI / Form CRS (if applicable).** Columns: obligation (disclosure / care / conflict / compliance / CRS-delivery), evidence_pin, last_review_date, owner_role, gap_flag.
- **Tab 10 — FINRA 3110/3120/3130/3310 (if applicable).** Columns: rule, element, last_attestation_date, evidence_pin, owner_role, gap_flag.
- **Tab 11 — Cyber / Reg S-P / NYDFS.** Columns: element, status, last_review_date, evidence_pin, owner_role, gap_flag.
- **Tab 12 — Mock-interview prep.** Columns: interviewee_role, question_id, question_text, prepared_response_anchor (evidence pin), rehearsal_status, owner_role.
- **Tab 13 — Gap and remediation list.** Columns: gap_id, domain, severity, description, owner_role, due_date, evidence_required, status, last_status_update.

The matrix is the reviewer's working artifact; the Word memo is the executive narrative. Both ship together.
