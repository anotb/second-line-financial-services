# Source anchors — evidence-request-builder

The named, dated regulatory and methodology sources this skill anchors to. SKILL.md cites this file by path and does not restate excerpts. Sector-specific and cross-cutting anchors live in the corresponding overlay files.

`[verify section]` placeholders mark anchors where the precise section reference still needs verification against the current edition of the source. They are deliberate, not omissions.

## Primary frame — engagement evidence and request hygiene

- **AICPA AU-C 500, Audit Evidence** (Statements on Auditing Standards, AICPA Professional Standards, current edition) [verify exact paragraph references — generally §05 through §A60 in the current AICPA codification on relevance and reliability of audit evidence; §A31-§A35 on evidence from external sources; §A38-§A41 on management-prepared schedules]. Methodology anchor for the relevance, reliability, and sufficiency frame the request list operates under. Used in second-line testing as the standard for distinguishing original system output from vendor-supplied and management-prepared evidence (the reliance classification on each request row). https://www.aicpa-cima.com/professional-standards (search "AU-C 500").

- **AICPA AU-C 230, Audit Documentation** (current edition) [verify paragraph references, generally §08-§14]. The request list is part of the audit-trail documentation. The "experienced reviewer" test bears on whether the requests are specific enough to be replayed: a reviewer reading the request list six months later should be able to reconstruct what was asked, of whom, by when, and what was received. https://www.aicpa-cima.com/professional-standards (search "AU-C 230").

- **AICPA AU-C 505, External Confirmations** (current edition) [verify paragraph references]. Used where the request list pulls evidence from external parties (customer confirmations, counterparty confirmations, vendor confirmations); the reliance classification `external-confirmation` triggers AU-C 505 conventions in the workpaper. https://www.aicpa-cima.com/professional-standards (search "AU-C 505").

- **IIA International Professional Practices Framework — Global Internal Audit Standards (effective January 9, 2025)**. Standard requirements on identifying information for engagements (the prior IPPF Standard 2310 — Identifying Information mapping) [verify section labels under the current 2025 IIA standard set]. Used by second-line testing programs as the methodology anchor on identifying sufficient, reliable, and relevant information to support engagement objectives. https://www.theiia.org/en/standards/ .

## Recordkeeping floors — bear on what the request list may legitimately ask for

- **Bank Service Company Act, 12 USC §1867(c)**: examiner-access posture for vendor systems the firm relies on for evidence; cite when a request asks a bank service provider for evidence and the firm is fielding the ask under its BSCA-covered contract.

- **BSA recordkeeping** — 31 CFR §1010.430 (record retention generally five years) [verify subsection]. Bears on what the request list may ask for from BSA-covered records and the period boundaries.

- **SEC Rule 17a-4 (17 CFR §240.17a-4)** — broker-dealer recordkeeping retention and format treatment. Bears on capital-markets evidence-request scope and the format options the request list may legitimately offer (preserved in non-rewriteable form).

- **FINRA Rule 4511 — General Requirements (Books and Records)**. Recordkeeping requirements that govern what a broker-dealer can produce on request.
